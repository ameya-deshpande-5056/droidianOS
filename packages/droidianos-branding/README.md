# droidianos-branding

Distribution identity files for droidianOS.

Brand direction:

- Debian Stable desktop base.
- Android applications presented as normal Linux desktop applications.
- Waydroid integration is hidden from the normal user flow.
- Unified settings, updates, permissions, and app management.
- Calm technical look: integrated, secure, lightweight, and auditable.
- No third-party logos, mascots, or Android subsystem-first artwork.
- Use one canonical mark everywhere: a cyan desktop host forms the "D" while one restrained amber bridge enters its center, representing controlled Android-to-Linux integration.
- Keep the mark flat and geometric. Artwork may add depth, but must not redraw or reinterpret the mark.

The package applies that identity to system metadata, the ISO and installed GRUB menus, Plymouth, GDM, LightDM, SDDM, desktop and lock-screen defaults, and desktop-base consumers including Plasma, Xfce, and LXDE.
