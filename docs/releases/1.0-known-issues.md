# droidianOS 1.0 Known Issues

- Flutter UI is not implemented; current installer/settings/software center UIs are Zenity MVPs.
- Android notification action buttons and inline replies are not implemented.
- APK icon extraction uses fallback icons.
- APK `@string/...` label resolution is not implemented.
- Per-update ID filtering is not implemented in the update service.
- Android image update availability check is not implemented.
- Shared-folder policy is persisted, but complete per-app mount enforcement is not implemented.
- ISO build requires `waydroid` to be available from an APT source during live-build.
