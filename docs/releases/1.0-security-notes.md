# droidianOS 1.0 Security Notes

## Update Trust

- Project packages are distributed through the signed project APT repository.
- Debian base packages come from Debian Stable and Debian security repositories.
- ISO checksums must be signed before publication.

## Android Application Isolation

- Android applications run through Waydroid.
- Shared folders must be explicitly configured.
- Full home directory sharing is not enabled by project policy.
- Runtime permission controls are exposed through `droidianos-permissionsd`.

## Known Security Limitations

- APK provenance and automatic APK update trust are not implemented.
- Notification action/reply bridging is not implemented.
- Shared-folder policy exists, but full per-app mount enforcement is incomplete.
- The current GUI tools are MVP Zenity frontends, not final hardened Flutter UIs.

## User Guidance

- Install APKs only from trusted sources.
- Keep Debian security updates enabled.
- Keep the project APT repository signing key installed through `/etc/apt/keyrings/droidianos.gpg`.
