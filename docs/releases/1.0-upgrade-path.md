# droidianOS 1.0 Upgrade Path

## Supported Upgrade Path

Supported upgrades require:

- Debian Stable base.
- Project APT repository configured.
- Project signing key installed.
- No manually removed core project packages.

## Commands

```sh
sudo apt-get update
sudo apt-get upgrade
droidianos-recovery restart
droidianos-integrationd --refresh
```

## Post-Upgrade Checks

```sh
droidianos-recovery status
droidianos-diagnostics ~/droidianos-diagnostics.tar.gz
```

## Rollback

Rollback is not implemented as an automatic system feature. Recovery is limited to reinstalling previous package versions from the APT repository if retained.
