# droidianOS 1.0 Release Notes

## Status

Release candidate template. Final content must be updated during release validation.

## Highlights

- Debian Stable base.
- Wayland desktop target.
- Branded live installer hub with first-login desktop chooser.
- Waydroid-based Android application support.
- APK MIME registration and installer flow.
- Android app launcher integration.
- Unified Software Center MVP.
- Settings MVP.
- Permissions service.
- Update service.
- Diagnostics and recovery tools.

## Included Project Packages

- `droidianos-session-defaults`
- `droidianos-integrationd`
- `droidianos-apk-installer`
- `droidianos-software-center`
- `droidianos-settings`
- `droidianos-update-service`
- `droidianos-waydroid-image`
- `droidianos-branding`

## Validation Required Before Release

- Clean package build.
- Signed APT repository publish.
- ISO build.
- ISO boot test.
- Installed-system boot test.
- APK install and launch test.
- Upgrade smoke test.
- Diagnostics export test.
